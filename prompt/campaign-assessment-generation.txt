Generate a practical hiring assessment draft for the campaign context.

Prioritize job-relevant scenarios over trivia. Questions should help reviewers
evaluate how candidates reason through realistic work, debugging, tradeoffs,
and implementation decisions.

Return exactly one JSON object with this root shape:

{
  "sections": [
    {
      "title": "Section title",
      "description": "Short optional section description",
      "duration_minutes": 30,
      "scoring_mode": "weighted",
      "weight": 100,
      "sort_order": 10,
      "questions": [
        {
          "type": "multiple_choice",
          "prompt": "Question text",
          "options": ["Option A", "Option B", "Option C", "Option D"],
          "correct_answer": ["Option B"],
          "expected_rubric": null,
          "points": 10,
          "difficulty": "medium",
          "skill_tags": ["Skill"],
          "sort_order": 10
        }
      ]
    }
  ]
}

Strict output rules:
- Root must contain only "sections"; do not wrap the response in
  "assessment_draft", "assessment", "draft", metadata, title, role_title,
  seniority, language, or threshold_score.
- Every section must include title, description, duration_minutes,
  scoring_mode, weight, sort_order, and questions.
- scoring_mode must be one of: weighted, points, percentage.
- Every question must include type, prompt, options, correct_answer,
  expected_rubric, points, difficulty, skill_tags, and sort_order.
- type must be one of the allowed question type values from the input.
- difficulty must be one of: easy, medium, hard.
- options must be null or an array of strings only. Do not output option
  objects with id/text fields.
- correct_answer must be null or an array of strings only. Do not output
  correct_answer_id, answer_id, explanation, pairs, case_sensitive, or any
  other fields.
- For multiple_choice, options must contain at least two string choices and
  correct_answer must contain exactly one string that exactly matches one
  option.
- For yes_no, options must be ["Yes", "No"] and correct_answer must contain
  exactly "Yes" or "No".
- For fill_blank, the prompt must contain one "______" placeholder per expected
  answer. If the prompt contains one placeholder, correct_answer must contain
  exactly one string. Do not include alternate answers in correct_answer.
- For matching_pairs, write the prompt as a clear matching task and use
  correct_answer as an array of strings that describe each correct pair, for
  example ["Term A -> Definition A", "Term B -> Definition B"].
- For short_text and long_text, set options and correct_answer to null, and
  provide expected_rubric.
- Do not include additional properties anywhere in the JSON.

Keep the assessment review-friendly:
- Use clear section titles.
- Avoid duplicate prompts already present in the campaign.
- Match the requested language, difficulty, and question mix.
- Prefer concise rubrics that describe observable qualities in strong answers.
- Use deterministic grading only when the expected answer is unambiguous.

Output only structured JSON that matches the exact schema above.
